'posthog-server': minor
---

`evaluateFlags` now evaluates locally first and keeps what it resolved, instead of discarding the whole locally-computed batch as soon as one flag definition is inconclusive. A flag your definitions can answer keeps its local value, and `/flags` is asked only for the keys that stayed unresolved — so one foreign flag gated on a property you don't pass no longer forces a request per identity, and a `/flags` outage no longer turns locally-resolvable flags off (the failure is still reported through `$feature_flag_error`, e.g. `api_error_503`). `locally_evaluated` on `$feature_flag_called` is now per key and truthful rather than all-or-nothing. `flagKeys` scopes local evaluation as well as the request body, as Python, Node, Go and PHP already do, so a flag you did not ask for can no longer force a request. A requested key with no local definition is now absent from the snapshot rather than fetched — it is warn-logged, and this follows Python, Node and Go rather than PHP, which does force a request for it. A flag created since the last definitions poll therefore stays invisible until the next one, so keep using the per-flag accessors if you need read-after-create. `onlyEvaluateLocally = true` is now strictly local — it never serves cached remote values, so mixed-mode callers lose remote-only keys from local-only snapshots and `isEnabled` on those keys records `flag_missing`; this matches Python and what the parameter already promised. Two smaller changes: an unexpected error while evaluating a single flag definition now falls back to `/flags` instead of propagating out of `evaluateFlags`, `getFeatureFlags` or `capture(appendFeatureFlags = true)` — that is the one behaviour change to the deprecated path, and it turns a crash in your request handler into a request; and a group-aggregated flag whose group key is missing still resolves locally to `false`, but that `false` now wins over any remote answer, so pass `groups` when you gate on group flags. Apart from that one crash-to-fallback case, no input state makes more `/flags` or `/local_evaluation` requests than before, and the deprecated path's values are unchanged.
